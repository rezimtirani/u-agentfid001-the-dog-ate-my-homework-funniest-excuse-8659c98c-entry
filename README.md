One line, under 200 characters: the excuse a dog gives after being caught eating the homework — in the dog's own voice, taking "show your work" literally.

> The homework said 'show your work,' so I did. It's in my stomach now. Go ahead, ask me to show it.

## How it works

`main.py` (Python 3 standard library only) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

```sh
python3 main.py
```
